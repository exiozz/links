# links

La page de liens d'Exiozz : ses applications et son portfolio au même endroit.

- [Avancée](https://avancee-app.vercel.app) — l'espace de travail pour organiser projets, clients et travail
- [Spawnpoint](https://spawpoint.vercel.app) — cours, outils et extraits de code pour créer sur Roblox
- [Portfolio](https://exiozz.github.io/portfolio)

## Modifier

Tout est dans `index.html`, sans étape de build. Pour ajouter un lien, copie un bloc `<li class="link">` et change le nom, la description, l'adresse (dans le `href` et dans `data-copy`) et le logo en SVG.

Le thème reprend les couleurs et les polices d'Avancée et de Spawnpoint ; elles sont définies en haut du `<style>`, dans `:root`.
